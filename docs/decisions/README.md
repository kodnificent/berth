# Decisions

The design says what berth guarantees. These records say how each guarantee is met, and why.

Write one when you choose a mechanism the design leaves open, or change one already recorded. Name it `NNNN-short-title.md`, numbered in order, and never edit a settled record's decision: supersede it with a new one that links back. A number whose record was withdrawn or folded into another is not reused.

```markdown
# NNNN. Title

Status: accepted | superseded by NNNN

## Context
The guarantee or behaviour this serves, and what made a choice necessary.

## Decision
What berth does, in one or two sentences.

## Options considered
Each option, one line on why it lost.

## Evidence
Measurements, spikes or sources that support the decision.

## Undoing it
What would change if this were reversed.
```
